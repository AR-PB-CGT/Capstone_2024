# 증강현실 기반 생성형 AI 스토리텔링 시스템을 활용한 독서 플랫폼 개발

Development of Augmented Reality-based Generative AI Storytelling Platform

## 개요
* 그림책을 포함한 아무 이미지를 촬영하면 해당 이미지를 바탕으로 이야기가 생성되며, 연속으로 촬영하여 이야기를 이어갈 수 있습니다.
* 카메라 외에도 개인 이미지 및 음성인식을 지원합니다.
* 그림책에 특화된 객체 감지 AI로 등장인물을 분석하여 상황에 맞는 동작을 취하는 3D 모델을 생성합니다.
* 변환된 등장인물은 손 제스쳐(잡기, 끌기)를 이용하여 AR 상호작용이 가능합니다.
* 태블릿용 웹캠 거치대를 3D 프린터로 직접 제작하였습니다.
* Android, Windows 환경을 지원합니다.
* 한국어 및 영어를 지원합니다(언어 추가 예정).
* 이야기의 문장 수준 조절 기능을 지원합니다.
